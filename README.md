# Démo Palm Garden

Démo de site réalisée par **Ferdinand.Dev** pour le restaurant-lounge Palm Garden à Bouaké. Ce n'est **pas le site officiel du restaurant**.

- Réservation de table et commande envoyées sur WhatsApp
- Page `menu.html` avec la carte complète
- Site léger en HTML, CSS et JavaScript, pensé pour le téléphone

La carte, les prix et les photos des plats sont des **exemples**. Les photos des plats viennent de Wikimedia Commons : auteurs et licences en bas de `menu.html`. Les photos du lieu viennent des publications publiques du restaurant et ne servent qu'à cette proposition.
